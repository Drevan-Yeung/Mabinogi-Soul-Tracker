# 释魂者武器制作追踪器

洛奇释魂者武器材料需求追踪器。  

## 在线使用

[点击打开追踪器](https://drevan-yeung.github.io/Mabinogi-Soul-Tracker/)

数据保存在浏览器本地。

## 使用说明

- 在材料行填写“已有”数量后，工具会自动计算还差数量，并在可宝珠兑换的材料下方显示还差对应多少宝珠。
- 可宝珠兑换的材料支持切换获取方式：`珠` 表示按宝珠兑换计入总数，`购` 表示用金币、人民币或其他方式直接购买，不计入宝珠总数。
- 觉醒力量之精髓默认是 `购`，不计入宝珠总数。比如总共还需要 200 个精髓，其中 100 个准备直接买，可以先在“已有”填 100，再把方式切成 `珠`，工具会只计算剩余 100 个需要的宝珠。

## 成本估算

点击材料需求标题右侧的“预算估算”打开成本面板。

- 面板会列出当前武器涉及的宝珠兑换类材料及总需求量。
- 每种材料可以填写人民币单价（元/个）或游戏币单价（亿金/个）。
- 顶部汇率用于把游戏币价格换算为人民币，例如 `1亿游戏币 = 140人民币`。
- 总预算会同时显示人民币和游戏币估算。
- “存快照”可以记录当前武器的一次价格结果，方便之后对比材料涨跌。
